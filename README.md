## ✨ Features

- 🍿 **Trending & Popular:** Stay updated with daily and weekly trending movies and TV shows.
- 🔍 **Smart Search:** Find any movie, actor, or genre instantly with autocomplete/real-time filtering.
- 📋 **Detailed Insights:** View cast details, user ratings, trailers, release dates, and plot summaries.
- 💖 **Personal Watchlist:** Save your favorite movies to watch later (stored locally or via account).
- 🎨 **Sleek UI/UX:** Responsive design optimized for desktop, tablet, and mobile viewing with dark mode support.
